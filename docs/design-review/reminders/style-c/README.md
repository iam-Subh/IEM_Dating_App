# Reminder artwork — Style C

11 PNG images, 1254 × 1254 pixels, with alpha transparency. Generated with the built-in image_gen tool.

Open index.html to review large and small versions. Select Dark, Light, or Transparency grid. The motion preview respects the system Reduce Motion setting.

Each PNG has a .prompt.txt file with its generation prompt, reference image and selected edit prompt. manifest.json records intended uses, dimensions and motion settings.
