# Explore demo

Open the Explore tab in a development build. Select Demo cards beside Discovery preferences.

The demo uses the same swipe screen as Explore. Swipe right to Like or left to Pass. Tap either side of a photo to change photos. Select the up arrow to expand the profile.

Like, Pass, Report, and Block use local handlers. Select Reset demo cards to restore profiles. Photos need an internet connection. Demo actions do not change server data.

The profiles test verification, shared interests, multiple photos, long details, missing details, and a missing photo.
